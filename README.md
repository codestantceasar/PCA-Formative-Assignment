Project Description

This project implements Principal Component Analysis (PCA) from scratch using NumPy. The objective is to reduce the dimensionality of an Africanized dataset while preserving as much variance as possible.

The PCA implementation includes:

Data preprocessing
Handling missing values
Standardization
Covariance matrix computation
Eigendecomposition
Explained variance calculation
Principal component selection
Data projection
Visualization before and after PCA
